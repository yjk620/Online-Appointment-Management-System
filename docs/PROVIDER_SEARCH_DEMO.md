# Provider search (#45)

Open Providers as a client. Search a provider name or description (case-insensitive), enable Only providers with open times, try a nonmatching query, then Clear provider filters. Existing provider details and booking are unchanged. Only future unbooked times qualify.

Demo: search Alex or career, try a nonmatching term, clear, then open a provider detail and return. Reuse the existing provider seed if needed. Run `cd frontend && npm test` (Node 22.6+).
